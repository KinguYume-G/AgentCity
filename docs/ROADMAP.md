# Roadmap

## Shipped
- 0.1: autonomous residents, construction, policies, local saves.
- 0.2: procedural 3D coastal city, camera, lighting, decorative traffic, 2D fallback.
- 0.3: inventory, business capital, output, social contacts, decision inspector, portable saves, modular source.

## Proposed
- 0.4: road network graph, walking routes, transit, travel time and congestion.
- 0.5: households, relationships, age progression, housing rent, company formation and demand.
- 0.6: scalable map, terrain, richer assets, visual effects and performance profiling.
- 0.7: scenario editor, objectives, economy balancing and replay.
- 0.8: optional LLM dialogue with explicit cost limits and secure backend; no API keys in client.
- 0.9: cloud persistence, multi-city simulation and accessibility improvements.
- 1.0: browser and device acceptance testing, stable releases, packaging and distribution.

These are planned capabilities, not promises or implemented features.
